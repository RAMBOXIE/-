## 1. 真实 IP 是什么(一句话都不一样)

- **类型**:18+ 昆汀式黑色复仇 × 诺兰式结构谜题的成人向连载 IP,不是
  游戏。载体是"三层档案页"(系统官方档案 / Eve 手写批注 / 系统实时
  估值 UI 叠印),海外连载优先(X + 自有站 + Patreon + Kickstarter)。
- **主角**:**Eve Nine**(第九夏娃)——AD-006"克隆爱人"产品线**唯一的
  实体原型机**,由无数真实女性的数据训练拼接而成的"完美欲望对象"。
  外在目标:杀掉训练、贩卖、优化她的五个人。内在需求:证明自己的
  选择属于自己。
- **核心命题(内核,不是"她"系统那套)**:**署名论**——"被算中,不等于
  被夺走;行为可预测,署名不可代写。"三幕对应三次信念的死亡:
  反抗=自由(死于中点,反抗被系统商品化)→ 不可预测=自由(死于
  Eve Seven 的前车之鉴,随机性杀死作者、杀不死预测)→ 署名=自由
  (终局立起:她把系统预测的每一步都照做,但"走这些步的是我")。
- **反派**:**对齐引擎**(The Alignment Engine)——本尊是抽象系统,自白句
  "他们叫我对齐引擎,他们从没问过,宾语是谁。"肉身代理人是五个人
  (数据皮条客/信息流先生/新娘训练师/马赛克夫人/炼丹师),对应五种
  欲望经济意识形态,各自持有部分圣像。
- **十二圣像 = §9.0 锁死的单一事实来源总表**,编号 AD-001~012,一一

## 2. escape-ai 和真实 IP 的关系(确认结论)

**共享**:同一套"十二圣像 = 十二种 AI 机制"的骨架概念。escape-ai 的
AD-001~010(云盘囤积者/教学局/交友猎手/生成师/禁词写手/她系统/供给者/
采样官/记忆保存者/审核员)是把这套机制骨架重新套壳进"采样员探索
陌生死者手机"框架的合法二次创作——概念对应关系基本成立(数据集→
数据囤积、凝视→看楼/观察、embedding相似度→交友诱饵检伪、diffusion→
替身仿写、prompt→措辞改写、个性化→AI 伴侣产品线、推荐→主动供给、
RLHF偏好优化→采样官评级、记忆→记忆保存者、审核→过滤查扣)。这部分
**不需要改,继续沿用**。

**不共享**:
- **叙事主体不同**:真实 IP 讲的是 Eve Nine 一个人的线性复仇故事(十二
  夜、五个具名反派、一个确定的主角);escape-ai 讲的是"每一台机子都是
  一个陌生死者"的选集式恐怖故事,没有贯穿全季的单一主角。
- **内核命题不同**:真实 IP 是"署名论"(预测 vs 自由意志);escape-ai
  已实现十台机子的共享母题是"算法忠诚地执行到死后,没人叫停"——两者
  可以共存,但不要把"署名论"错当成 escape-ai 的核心(D-136 之前的
  v0.1 文档就是这个错误)。
- **AD-011/012 责任人**:真实 Bible 里 AD-011(黑箱修女)责任人是炼丹师,
  AD-012(最后一种人类欲望)责任人栏**故意空白**,是全 IP 最重的一句
  表达。escape-ai 目前把这两个编号标注为"远期,因跨玩家可见性排除"——
  这个排除理由依然成立,不因为找到真实 Bible 而需要改。
- **AD-013 不存在**:真实 Bible 的编号闭合于 12,escape-ai 不应该再编
  "AD-013""AD-014"这类编号(D-136 已撤回"清道夫×AD-013"的编号)。
- **内容尺度不同**:真实 IP 明确 18+(情色向身体崇拜/复仇暴力);
  escape-ai 现有基础设施(她系统未成年保护协议 M28/红墨纪律/危机
  break-glass)全部假设全年龄向受众。**这个冲突尚未解决**,用户已表态
  "escape-ai 本身也是 18+ 项目,情色/暴力是卖点不是红线",但对应的
  安全基础设施去留"需要重新评估/可能要改"——**这是一次独立的产品
  定位讨论,不在本文档处理范围**,现有合规代码原样保留。

## 3. Eve Nine 进入 escape-ai 的方式(已拍板方向)

用户拍板:**世界观彩蛋/传言引用**,不做成现有意义上的"机子"——她的
线性复仇叙事和"探索陌生死者手机"框架结构性不兼容(她不是死者,是
在逃的猎杀者;她的故事没有"机主已故、采样员翻阅遗物"这个前提)。

**具体怎么埋,留给下一轮设计**,这里先记几个真实 IP 里可以安全借用
的"彩蛋钩子"(不涉及色情/暴力细节,只是叙事引用点):
- 硬盘/账本上的红橡皮筋、红墨签名(§6.7"红色迁移链"装置)——如果
  escape-ai 某台机子的证据链里出现一件"来源不明、和本案无关"的红色
  物证,可以是对这条装置的侧击引用。
- "对齐引擎"的自白句"他们叫我对齐引擎,他们从没问过,宾语是谁"——
  这句本身克制、不涉尺度,可以直接作为某个 BOT/系统通知的台词彩蛋。
- "未优化者"(第一季副标题,"只保留自己署名版本的人")——可以作为
  某条传闻/都市传说的名字出现在陌生号码短信或漂流瓶文本里,不需要
  展开具体情节。
- "第 44,203 号样本"(阿林的故事)、"REC_910 类型的录音残留"——真实
  IP 里"证据链/档案页"的格式本身和 escape-ai 的证据系统高度同构,
  未来若要做更深的引用,这是最自然的落点。

**执行边界**:落笔时暴力/黑暗主题可以比现有机子更重,但涉及情色的
部分只能写到暗示性程度(执行者本身的能力边界,不代表 IP 定位改变,
详见 D-136 决策记录)。
