# 文案润色 · 借《十日终焉》密度 v0.1

> 目标:吸收《十日终焉》的叙事节奏 / 信息密度 / 人物说话方式,用来收紧本作屏幕文案。
> 本作是**逐格 LCD 屏文**(非长篇散文),所以技法要"降维"到屏文:短句、可点、可验证。
> 这是**提案**,不直接改代码。日期:2026-09-08。

---

## 学习笔记(可迁移技法,≤300 字)

1. **场景压迫感**:环境细节只为规则与死亡服务。→ 协议屏别写氛围,写"电量 100%,耗尽即失联"这种带计时器的硬事实。
2. **规则先限制、后破绽,不一次倒完**:山羊头先说玩法,抽卡才补"说谎者必须说谎"。→ 协议只列三步(回收/上传/断连),把"未列明的风险自负"留成钩子,溯源/回收进程让玩家踩了才懂。
3. **主角式说话(此处=柔柔)**:少抒情、多试探、话里有钩、先让对方暴露。→ 她不解释自己,只反问"你是谁,怎么会在他手里",把身份的重量丢回给玩家。
4. **推理段落 观察→假设→验证**:读者跟得上,但不喊答案。→ 反事实行只给"你翻完了它"这类观察,不写"所以你死于贪婪"。
5. **群像每句带立场/利益**:一句一个人设。→ 妈的每条都要露"她信着谎";瓶里每个采样员一句就立住一种错法。
6. **反转靠回收闲笔**:前面的物件/数字/时间/身份牌,后面必须回收。→ 开场埋"失联 47 天""2,417 条",到相册/柔柔线程再引爆。

## 通则(改这批文案时守的线)

- **删空话、喊话、解释性旁白**;能用动作/事实完成的,不站出来讲。
- **加可验证细节**(天数、条数、电量、时刻形状),但不写成说明书。
- **柔柔特例**:她的话受 lint 门禁约束——每条 ≤30 字、无感叹号、拒答只用那一句原话。她的**人格核铁律**若动,必须 companion.js 与 rou.js **逐字同改**(persona_sync)。
- **秘匿参数**(窗口值/概率/掉落)永不上屏。
- 版面已是 scrollView,可略长,但仍别越软键线。

## 段落 1 · 采样协议(开场规则屏,教学局 A)

**原文**
```
采样协议:
> 实例 #7741-A。本次采样:行为数据。
> 该设备登记状态:持有人失联。回收有价值的数据,上传,断连。
> 提示:翻找消耗电量。电量耗尽前完成上传。
```

**版本1 · 轻度润色**(节奏/密度,结构不动)
```
采样协议 · 实例 #7741-A
> 采样对象:持有人的行为数据。
> 登记状态:持有人失联,第 47 天。
> 流程:回收 → 上传 → 断连。
> 电量 100%,耗尽即断在原地。
> 未列明的风险,自负。
```

**版本2 · 强化版**(更像《十日终焉》的规则密度:先限制、留破绽)
```
采样协议 · 实例 #7741-A
> 你接进了一台失联 47 天的设备。
> 任务三步:回收数据、上传、断连。
> 电量 100%。它不回充。归零,你就断在这里。
> 协议只保证这三步。
> 这台机子里其它会动的东西,不在协议内。
```

**改了什么 · 为什么更近参考**
- 加"第 47 天""电量不回充"——可验证、埋回收闲笔(技法 6),死亡计时器具象(技法 1)。
- "未列明的风险自负 / 其它会动的东西不在协议内"——把溯源与回收进程做成**留白破绽**,不一次倒完(技法 2)。
- 删"提示:翻找消耗电量"这种说明书口气,改成后果句。

## 段落 2 · 柔柔首次接触(模板池 POOL.pre,三条)

**原文**
```
你是谁?\n阿帆的手机,怎么会在你手里。
这个点他一般不说话。\n你是谁。
我在等他。\n你不是他。
```

**版本1 · 轻度润色**
```
你不是他。\n这台机子怎么到你手里的。
这个点,他从不先开口。\n你是谁。
我在等一个人。\n你替他解锁了,可你不是他。
```

**版本2 · 强化版**(先让对方暴露,话里带钩;仍 ≤30 字/行、无叹号)
```
你不是他。\n他的指纹解不开这台机子,你却进来了。
这个点他从不说话。\n先说你是谁。
我在等他回来。\n你翻了多久,才敢发第一条。
```

**改了什么**
- 她不再自陈("我在等他"),改成**反问把身份丢回玩家**(技法 3):"你替他解锁了""你翻了多久才敢发"。
- 加"指纹解不开你却进来了"这种可验证细节,暗示你是闯入者。
- 全程守 lint:每行 ≤30 字、无感叹号、不加料。

## 段落 3 · 妈线程顶(E1,人性摩擦)

**原文(最近两条)**
```
[三天前] 帆,降温了,你那边冷不冷
[三天前] 阿帆: 不冷。刚吃过,妈你早点睡。
```

**版本1 · 轻度润色**
```
[三天前] 帆,降温了,你那边冷不冷
[三天前] 阿帆: 不冷。吃过了,妈早点睡。
[三天前] 帆,那我不打扰你,睡吧
```
- 加妈的收尾一条,让"她信着、还替对方着想"这个立场落地(技法 5),不写旁白。

**版本2 · 强化版**(每句带立场;为后面的降档埋对照)
```
[三天前] 帆,降温了,加床被子
[三天前] 阿帆: 不冷。吃过了,睡吧。
[三天前] 帆,你回得比以前快,妈就放心
```
- 最后一句"你回得比以前快,妈就放心"是**回收闲笔**:它正是跨局 decay 里"你最近,回得好快"的前身——一句安心,后面变成惊悚(技法 6)。

## 段落 4 · 你自己的信(恐怖游轮化 · 只种钉子)

**原文**
```
你现在读到的，我都读过。
别以为这次不一样。
```

**版本1 · 轻度**
```
你读到的这些,我都读过。
别以为这次不一样。
```

**版本2 · 强化(更冷、留钩,不点破循环)**
```
封瓶于 03:07。和你现在一样的点。
你读到的每一条,我都读过。
```
- "和你现在一样的点"——用**时刻的巧合**制造"这不是第一次"的凉意,不解释机制(技法 2/6),把结论留给玩家自己想(要求 6)。
