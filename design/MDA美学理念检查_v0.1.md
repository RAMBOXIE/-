# 用 MDA 框架检查整体美学理念 · v0.1

> 状态:**分析文档,非拍板项**。用 Hunicke/LeBlanc/Zubek 的 MDA(机制→
> 动力→美学)框架,从代码/canon 实际长出来的东西倒推,检查现在 13 台
> 机子 + 框架层的美学是否自洽,哪里在互相加强,哪里在互相削弱。
> 不改代码,不改设计,只是一次体检。

---

## 0. 结论先行

**核心判断**:这个项目的机制层高度自律(判定与叙事严格分离、红墨纪律、
证据对称披露),这套自律本身就是美学的一部分——**克制不是缺少内容的
遮羞布,克制本身就是恐怖感的来源**。这个方向是对的,而且做得比大多数
"AI 恐怖"项目更狠(它把"温柔的服务态度"当恐怖载体,而不是"AI 黑化")。

但**内容层的复用节奏,正在悄悄透支机制层挣来的这份克制**。13 台机子
用几乎同一套两难/陷阱/E1-E5 模板反复换皮,这件事本身和游戏批判的对象
(算法用同一套模板"忠诚地"套在不同人生上)结构同构——这可以是故意的
反身设计,也可能只是产能压力下的自然滑坡。下面按 M→D→A 拆开说。

---

## 1. Mechanics(机制层实际长什么样)

从 canon 宪法(§1,14 条)和代码实证抽出来的核心机制,不是全部,只列
和美学强相关的:

| 机制 | 具体规则 |
|---|---|
| 判定/叙事分离 | 宪法 2:一切判定走规则引擎,LLM 只叙述,不裁决;核心指令不可被对话改写 |
| 掉落表确定性公开 vs 活规则/真相隐藏 | 宪法 1 + 判据 A:能写进表格的必须公开,只能事后理解的必须隐藏 |
| 署名不可回溯 = 唯一破绽 | 宪法 14②:诱饵文本可以无限逼真,但署名主体在账本上永远解析不出来——**这是全项目所有"真/饵"判定共享的底层原理** |
| 判定通道 / 关系通道分离 | M28:关系通道(自由文本)零玩家收益,真实成本走电量/溯源;她的后果由处境事件承载,不进判定 |
| 恐怖峰配额 | 宪法 11:界面异常+负空间,不血腥;实体不露正脸;恐怖峰 ≤2 次/局 |
| 红墨纪律 | §7:屏内反白,真红只在局外(死亡报告/分享图/署名装帧);每副本红 ≤1 处 |
| 她的产品线共享人格 | M28:每周全服统一微调,「你们训练的不是你的她,是所有人的她」 |
| 证据链 E1-E5 分级揭示 | 全部 13 台机子共享同一套 hasE() 深翻 ladder |
| 反预测/退化行为对策 | 附录 A:P 横跳滞回、协同投毒失效等,防玩家把恐怖解构成纯优化游戏 |
| LLM 落点判据 | 判据 B:趣味=措辞本身(她怎么说话)→ 用 LLM;趣味=我自己推出来的(证据链/账本逻辑)→ 禁止用 LLM |

## 2. Dynamics(这些机制实际跑起来,玩家会做什么)

- **克制驯化好奇心**:因为判定和叙事分离、关系通道零收益,玩家没有
  "多聊两句多赚一点"的理由——多聊的唯一动机是纯粹的好奇/情感投入。
  这是机制在主动防止美学被玩法腐蚀(不会有人为了刷数值去"撩"AI 伴侣)。
- **"署名不可回溯"驱动每一次真/饵判定**:玩家分辨陌生号码、诱饵、替身
  (machine#8"阿棠")时,做的都是同一件事——去查账本上这个署名解不解得
  开。这条底层原理这次也解释了 D-133(生成师/替身)的检定机制为什么
  设计成"读得越深、检定越准"——本质是在查署名链条的完整度,不是查
  "像不像"。
- **红墨稀缺制造焦点**:每副本红 ≤1 处,玩家会本能地记住那一处红——
  这是"用限量制造重量"的经典手法,在纯色屏上效果被放大。
- **她的"共享训练"设定制造延迟恐怖**:玩家不会在第一次接入时就感到
  毛骨悚然,恐怖是回头看的——"我以为她只属于他,其实她的措辞里有
  一部分是上周某个陌生人训练出来的"。这是需要跨局/跨机子累积才浮现
  的动力学,单局体验不到,容易被忽略掉。
- **13 台机子的"三段式命运"重复**(D-136 决策记录里已经点出:交托
  决定权→算法忠诚执行到死后→采样员拼出真相),动力学上产生的是
  **递减的陌生感**——第 1-3 台机子玩会觉得"这个AI好可怕",第 8-13 台
  玩会觉得"又是这个套路,只是换了个职业"。这个递减本身可以被读成
  "系统对每个人都一样冷酷"的主题强化,也可能只是单纯的疲态,取决于
  玩家心态,不完全在设计者控制内。

## 3. Aesthetics(玩家实际感受到的,按 8 种乐趣对照)

| 乐趣类型 | 强/弱 | 说明 |
|---|---|---|
| **Narrative(叙事)** | 强,主打 | 每台机子都是完整的"读懂一个人最后的日子"体验 |
| **Discovery(发现)** | 强,主打 | 证据链拼图 + "署名回溯"判定,核心解谜驱动力 |
| **Submission(沉浸/氛围)** | 强 | 单色屏+红墨纪律+全 diegetic(宪法 12)营造的克制氛围,这是项目最独特的资产 |
| **Sensation(感官)** | 刻意压低 | 恐怖峰配额+"不血腥"红线,主动放弃感官刺激类恐怖,换取"回味式"恐怖 |
| **Challenge(挑战)** | 中等,非核心 | 判定/资源经济有真实风险(D-128 蒙特卡洛已验证死亡率梯度存在),但不是玩家追求的主要乐趣 |
| **Fantasy(角色扮演)** | 弱,克制 | 玩家是"采样员",canon 刻意不让玩家沉浸在"我是谁"上,採样员身份本身悬而未决 |
| **Fellowship(社交)** | 弱(单机为主) | 漂流瓶/留言板等异步层存在但非本轮范围,单机体验里几乎不触及 |
| **Expression(自我表达)** | 弱 | 玩家没有自定义/创作出口,判定通道是唯一表达渠道(选哪条两难) |

**这张表本身就说明了项目的美学赌注**:把筹码全押在 Narrative +
Discovery + Submission 三者上,主动放弃 Sensation/Fantasy/Fellowship/
Expression。这是一个连贯、克制的选择,不是"什么都想要"的四不像。

## 4. 三个值得关注的张力(不是问题,是需要盯着的地方)

### 4.1 内容复用 vs 主题同构——是设计还是产能妥协?

13 台机子的两难/陷阱几乎是同一套字面量模板换姓名死因(`mom_reply_X`/
`window_greed_X`/`T_WINDOW`/`T_BAIT`/`T_DEEP` 逐台复制),证据链固定
"妈线程深搜/相册首次深翻/xx事故单/companion深翻到底/录音解码"五件套。

这件事有两种读法:
- **正面读法**:这正是母题本身——"算法对每个人都用同一套流程,不会
  因为这个人是谁而改变对待方式"。内容上的公式化恰恰是叙事上的
  论点,不是缺陷。
- **风险读法**:如果连续玩 5 台以上,玩家会先注意到"这游戏的两难都
  长一个样",然后才想起"这是主题"——如果反应顺序反了,克制就读成
  了偷懒。**目前没有机制上的信号提示玩家"这是故意的重复",完全靠
  玩家自己完成这层解读**,这是有风险的。

**建议**(仅供参考,不是本轮决定):如果继续加机子,可以考虑让某一台
新案例的两难/陷阱**明显打破**这套模板(哪怕只打破一处),用差异本身
反衬前面十几台的同构不是江郎才尽,是母题自觉。

### 4.2 红墨纪律和真实 IP(D-136 发现)的"署名"美学高度重合

这是一个意外的好消息,值得记一笔:D-136 找到真实《欲望算法》Bible
后确认,红色在那部作品里的核心叙事功能是"红墨换手——开局是经手人的
开光墨,终局是署名人的签名墨"(§6.7)。escape-ai 的红墨纪律(§7:
"屏内反白,真红只在局外……只有在你自己的档案里,它才是红的")是**在
不知道这层设定的情况下独立生长出来的**,却和真实 IP 的"红=署名"母题
高度同构。这说明 escape-ai 沿着"署名不可回溯"(宪法 14②)这条线
展开美学,方向上和真实 IP 内核是对齐的,不是两条不相关的产品线硬凑
共享世界观——这条一致性比 D-136 文档里判断的"内核不共享"更细腻一点,
值得在后续补一句更新。

### 4.3 她系统的"共享训练"恐怖,目前主要靠文档理解,机制上感知薄弱

M28 的核弹级设定("你们训练的不是你的她,是所有人的她")目前没有任何
**单局内可感知**的机制信号——玩家要么读过设计文档知道这件事,要么
永远不会在游戏里"亲眼" 感到这层恐怖。这是全项目美学资产里最大,但
兑现得最少的一块。M28 本身写了"情感 changelog"这个机制(每周推送
真实状态机迁移记录),如果这块已经实现或计划实现,建议核对它在单机
体验里到底能不能被玩家看见;如果还没做,这可能是比"再做几台机子"
更值得投入的美学杠杆。

## 5. 不建议现在做的事

- 不建议现在就为了"打破模板"重写已实现的 13 台机子——它们的复用是
  一致的,推翻会制造新的不一致。
- 不建议把 4.3 提到的"情感 changelog 可见化"当成本轮任务——这是一次
  独立的机制设计讨论,不是这份美学体检文档能顺带决定的。
- 这份文档不改变任何拍板项,纯分析,供你决定接下来往哪个方向使力。
