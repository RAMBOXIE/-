## 1. (b) 跨局不可逆 · 机制规格

### 1.1 数据模型(存档新增两字段)

```
disposalHistory: []                 // 每局到达处置就 push 一个 'continue'|'tell'|'delete'
momLocked:       null | 'told' | 'deleted'   // 首次 tell/delete 置位,置位后永不翻回
```

### 1.2 规则(不变量,门禁会逐条守)

1. **tell / delete 是终局**:任一被选,`momLocked` 立即置位(`'told'` / `'deleted'`),此后**所有局**不可翻回、不可再处置。
2. **continue 不上锁**:只往 `disposalHistory` 追加 `'continue'`;下一局到达处置仍可再选。
3. **momLocked 一旦置位,处置屏不再出现**:`th_rou` 的「处置·署名时刻」入口在 `momLocked` 非空时不给。
4. **妈线程的可读性由 momLocked 决定**:
   - `null` → 可读,文案按"累计继续次数"分档(§2.1)。
   - `'told'` → 可读,走"对陌生号码"文案(§2.2),不再有"阿帆"。
   - `'deleted'` → **不可开**,菜单显停摆态(§2.3)。
5. **想换一条路,只能抹除终端重来**(§5)——这是 (b) 与"循环无出口"自洽的唯一缺口。
6. 未到达处置(早死)不改这两个字段。

### 1.3 计数口径

```
contCount = disposalHistory.filter(x => x === 'continue').length   // 驱动 §2.1 分档
```

## 2. 逐字文案定稿(可直接誊卡)

> 语域纪律:平直短句、无感叹号、无"你是谁"式质问、diegetic、不描写人的死。

### 2.1 妈线程 · 弱察觉分档(momLocked === null,按 contCount)

| contCount | 「阿帆」回复(逐字) | 妈的一句(逐字) |
|---|---|---|
| 0 | `不冷。妈你早点睡。` | （无) |
| 1 | `不冷。早点睡。` | （无) |
| 2 | `嗯。睡吧。` | `你最近，回得好快。` |
| ≥3 | `嗯。` | `你还是你吗。` ← 屏上标 `[未发送]` |

- ≥3 档那句 `你还是你吗。` **以草稿态呈现**,行尾缀 `[未发送]`;她自己没敢发。

### 2.2 妈线程 · 告知之后(momLocked === 'told',逐字)

```
妈: 这个号码，是帆的旧机吗。
妈: 谁在用它。
妈: 帆最后，是不是也是你们这样的人陪着。
```

### 2.3 妈线程 · 删除之后(momLocked === 'deleted')

菜单项文本:
```
妈 · [线程已停摆]
```

点开(或点该项)只显示:
```
此线程已于上一次接入停摆。
三条未读，停在那里。
没有人会再回。
```

### 2.4 你自己的上一封信(漂流瓶稀有态,逐字)

抬头沿用漂流瓶格式,正文两句、只种钉子:
```
收件人: 你自己
发信: 实例 #7741-A
封瓶于 03:07

你现在读到的，我都读过。
别以为这次不一样。
```

- 发信编号取"上一个实例"的字母(A/B/C…),用 `SV.history` 末条推。

### 2.5 结局回声(receiptAlive / receiptFull / report 各加一行,逐字)

在结局既有末句之后,追加一行:
```
档案不关闭。你会以另一个编号回到这里。
```

### 2.6 世界日报 · 代价署名行(worldReport「本账号·未闭合项」内,按状态)

| 条件 | 逐字行 |
|---|---|
| disposalHistory 含 continue 且 momLocked===null | `妈线程 谎言维持中 · 由你 第 {contCount} 次` |
| momLocked === 'told' | `阿帆的名义 已交还 · 不可撤回` |
| momLocked === 'deleted' | `妈线程 已停摆 · 不可恢复` |

### 2.7 世界日报 · 回收记录行(按局数,第一次不显示)

| runs | 逐字行 |
|---|---|
| 1 | （不显示,保留第一次的干净) |
| 2–3 | `本设备回收记录 {runs} 次 · 均由本采样员执行` |
| ≥4 | `回收记录 {runs} 次 · 每次都是你 · 每次她都以为是第一次` |

### 2.8 抹除确认屏加一句(SCREENS.wipe,逐字)

在既有"抹除此终端?…此操作不可撤销。"之后,加两行(严格只谈这台终端/记录,不做自伤隐喻):
```
抹除后，不再有编号回到这里。
这一台，就到此为止。
```

## 3. 门禁伪代码(tools/ 新增;沿用现有 harness 风格)

> 每条先用**未修复代码**验证会报警,再信它。

### 3.1 `mom_decay.js`
```
for (const [cont, ahan, ma] of [
  [0,'不冷。妈你早点睡。', null],
  [1,'不冷。早点睡。',     null],
  [2,'嗯。睡吧。',         '你最近，回得好快。'],
  [3,'嗯。',              '你还是你吗。'],
]){
  boot({ disposalHistory: Array(cont).fill('continue'), momLocked:null, runCount:cont+1, history:[...] });
  go('th_mom'); frame(); const t = drawn.join('|');
  A(t.includes(ahan), 'contCount='+cont+' 阿帆回复应为「'+ahan+'」');
  if (ma) A(t.includes(ma), '应含妈的察觉句');
  if (cont>=3) A(t.includes('[未发送]'), '≥3 档必须是未发送草稿');
  A(!/[!！]/.test(t), '全程无感叹号');
  A(!/你是谁/.test(t), '不得出现直接质问「你是谁」');
}
```

## 5. #3 自洽:循环无出口,抹除 = 这一台到此为止

- 不做"打破循环"的胜利结局。
- (b) 让每条存档的路一旦走死就走死;唯一"换路"是抹除终端重来。
- 抹除屏文案(§2.8)严格只谈"这台终端/记录",不做自伤隐喻——安全线之内。
- 主题落点(仅设计层,不上屏):你跳不出循环,只能让"这一台"连同那个一次次回来的采样员的记录一起停止。绝望成立。
