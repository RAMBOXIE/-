# 《欲望算法:逃离AI》数值体系 v1.0 —— 使用说明

文件:`design/数值体系_v1.0.xlsx`
数据源:`M1_纸面原型_失踪采样体的手机_v0.4.md` §0.2/§0.5/§0.6/§5.1、`js/engine.js`、`js/content.js` + 本轮新增动作(拨打电话 / 播放录音 / 相册加深 / 妈线程 3 层 / 力竭结算态)。
生成方式:python + openpyxl。**openpyxl 不执行公式**——用 Excel / WPS 打开时才会算出数值;打开即自动重算,无需任何操作。

---

## 一条总规则

**「参数」表是唯一数据源。** 其余五张表(除「校准记录」的静态行)全部用跨表公式 `=参数!$B$n` 引用它。要调参:**只改「参数」表 B 列的蓝字**,保存,其他表全部即时重算——这就是"模拟"。不要直接改「动作成本表」或「教学局模拟」里的数字(那里全是公式,改了就断链)。

---

## 每张表怎么用

### 1. 参数
所有可调值一处集中,按区分组:全局 / 动作成本·电量 / 动作成本·信号 / 违规经济 / 判定 / 失真档阈值 / 缓存价值 / 上传。
每行:参数名 / 值(蓝字=可改)/ 单位 / 出处(v0.4 §0.2、engine.js 或"本轮新增")/ 备注。
- "力竭结算态"行是登记行(电量归 0 → 死亡,缓存散佚),值本身不参与计算。
- "上传电量预留比例 30%"来自备忘二"电量留三成给上传",只用于教学局模拟的检查列。

### 2. 动作成本表
完整动作清单(§0.2 全量 + 本轮新增),列:动作 / 电量 / 信号 / 缓存格 / 缓存值 / 时钟(分)/ 风险与判定 / 备注。数字列全是公式。
注意三处口径:
- **拨打电话**不属于"回复消息",不走违规经济——窗口内拨打也不违规(备注里写死了)。
- **窗口内回复**拆成两行:首次 +8(warning shot,非致死)/ 二次 +15 且 90 档遭遇。
- **相册深翻**拆成三行:第 1 次 +340(4格)/ 第 2 次 +120(2格)/ 第 3 次归档边界(无收益,深搜成本照扣)。

### 3. 教学局模拟(核心表)
逐行模拟"贪婪全翻死亡链"(canonical path):开机 → 协议回复 → 备忘 2 条 → 通讯录 → 妈线程 3 层 → 相册 3 翻 → 8873 → 录音 2 条 → 拨打 1 次 → 柔柔 2 滑 → 已删除 → 上传 2 回合 → 终局。
每行电量余 / 信号累计 / 档位(按 40/70/90 阈值的 IF 公式)/ 缓存累计 / 时钟(TIME 公式,每动作 +4 分)全部级联。**改参数表任何值,整条链即时重算。**
- 末行汇总:死亡时点电量、信号档、缓存总值、上传前电量、理论上传回合数。
- 检查列:每行电量 ≥0(PASS 绿 / FAIL 红);底部两条总检查:全程电量 ≥0、上传前电量 ≥ 三成。
- 已删除行的 25% 遭遇按**未触发**模拟(触发时的代价见判定表降档行:电量 −20 / 缓存损毁 10–20% / 信号 +10,可手动叠加感受)。
- 时钟为纯 +4 推进,未模拟拨表规则(03:02 / 03:34 事件时间戳)与 03:02 违规支线——canonical 贪婪链不含违规。

### 4. 判定表
d100 四档成功率(70=78 / 90=55 / 终局=60 / 自救=50)+ 省电修正后实际值(公式:基础 −15)+ 教学局 90 档降档规则 + 【固定】/【真掷】口径。改参数表的判定区,这里跟着变。

### 5. 失真档
信号 0–39 / 40–69 / 70–89 / 90+ 四档 → 渲染参数(threshold .42/.44/.47/.51、corrupt .0004/.0035/.011/.029、flicker 0/.02/.05/.10)+ 玩家可感症状。信号区间由参数表阈值联动;渲染参数是字面值(改档位手感直接改这里)。

### 6. 校准记录
静态记录蒙特卡洛第一轮结论:朴素策略生还 33% / 知情策略 37% 且提取 +52% / near-miss 41–44%。口径:violation warn 首次 +8 / 二次 +15(有一行公式与参数表联动,口径改了会对不上,提醒你复跑)。**原型定稿后需按新口径 + 本轮新增动作复跑第二轮。**

## 怎么调参(示例)

1. **"拨打电话太便宜了"** → 参数表"拨打电话·电量"3 改 4 → 动作成本表、教学局模拟第 17 步之后整条电量列自动下移 1。
2. **"想让贪婪链死得更早"** → 调"深搜·电量"或"开挂标记目录·信号",看模拟表死亡时点电量/信号档位怎么动。
3. **"想验证省电惩罚够不够狠"** → 判定表"省电修正后"列即时显示 63/40/45/35。
4. 改完看模拟表底部两条 PASS/FAIL:全程电量 ≥0 必须 PASS(否则链条中途力竭,死因变了);"上传前 ≥ 三成"在贪婪链上**预期 FAIL**——那是"贪的死在传输条上"的量化呈现,如果它变 PASS 了,说明贪婪链不再有惩罚,数值反而崩了。
