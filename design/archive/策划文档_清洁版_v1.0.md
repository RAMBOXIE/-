## 1. 一句话与体验

你捡到一台失踪者的手机,在一个凌晨的时间窗口里,被一个会下命令、会打分的采样系统逼着回收死者的数据、决定如何处置他留下的一切;手机里的 AI 伴侣「柔柔」在观察你,替她的主人已回复了他母亲 47 天。

**体验三层**:玩家 vs 副本(微恐怖搜打撤)/ 玩家被母体施压(采样指令)/ 玩家 ↔ 玩家(异步漂流瓶)。

**核心美学**:哑机 LCD 单色磷光;界面之诡的微恐怖;署名的重量;循环的绝望;智斗系统的爽。
**载体**:Web,移动优先;单局 8–15 分钟;离线/无 LLM 亦完整可玩。

---

## 2. 世界观与角色阵容

- **母体 / 对齐引擎**:更高维的采样计划本体。抽象、不露正脸。玩家看不到它,只感受它的规则与命令。
- **采样官(权威 AI · 声音/频道)**:母体在本终端的发令者与评级者。语气**挑衅激将、反复无常**。它下达采样指令、给你打分、逐局加码。不露正脸——它是采样终端里的一个冷频道。**它与柔柔对称:采样官=权威,柔柔=亲密,一台机子里两种 AI 声音夹着你。**
- **柔柔(亲密 AI · 关系通道)**:手机里的伴侣实例,登记用户沈一帆(阿帆)。阿帆已病逝 47 天,生前委托她以他的名义回复所有来信,包括他母亲。她执行了 47 天。她在核验、观察这个陌生接入者(你)。
- **妈**:阿帆的母亲。永远在线程另一端,你够不到。她是算法冷酷的人性标尺。
- **阿帆**:已故的登记用户。只存在于旧消息里。
- **采样员(你)**:接入者。母体采样计划里的一个执行单元、一个可回收的实例(#7741-A/B/C…)。
- **异步采样员**:其他玩家/canon 实例,通过漂流瓶留言(#6404-C 等),以及——「上一个你」。

## 3. LLM 如何作用于游戏 ★

**必须清楚的一条:LLM 只渲染两个 AI 角色的措辞,不裁决任何游戏内容。**

### 3.1 LLM 只碰这两处
- **柔柔**(关系通道:对她的自由文本短信)。
- **采样官**(发令/评级的措辞与态度)。

**其余一切都与 LLM 无关**——搜打撤、判定、掉落、缓存、溯源、电量、处置、证据链、妈线程、结局、世界日报、采样指令的**内容本身**,全部由状态机决定。宪法 2:LLM 只叙述,不裁决。

### 3.2 采样官比柔柔更"状态机"
- 采样官下什么指令、你达标没、评级几档、下局加码多少——**全在状态机**(指令从一个封闭指令库抽)。
- LLM 只给这些**已定好的指令套一层挑衅的措辞**。所以**离线也能完整玩**:无 LLM 时用手写的挑衅模板措辞,机制一分不少。

### 3.3 三级降级链(柔柔与采样官同架构)
渲染一句 AI 台词时,按顺序尝试:
1. **平台能力**(`window.claude.use('sample')`):在 claude.ai 上作为 Artifact 运行时。
2. **后端代理**(`/.netlify/functions/rou`):自托管(Netlify)时;人格核在服务端 system 参数,不在客户端。
3. **模板池**(手写台词):以上都不可用时(离线、或未配 key)。**这也是当前公网线上的实际状态——未配 key,走模板池。**

### 3.4 铁的纪律(已实现,门禁守着)
- **人格核在服务端**(Messages API 顶层 system 参数),客户端只送"玩家消息 + 已解锁的白名单状态标志"。
- **秘匿参数**(窗口真值/概率/掉落)**永不进任何送 LLM 的 prompt**。
- **assistant 轮验签(HMAC)**:防"伪造模型已答应过"的越狱。
- **输出 lint**:客户端再过一遍(≤30 字/行、无感叹号、拒答均匀、不泄机制)。
- **危机 break-glass**:自伤话题跳出虚构,给真实援助信息,不送 LLM。
- **成本**:限流 + 501 永久降级模板池;真正的硬上限靠 Anthropic 账务级支出上限。

### 3.5 结论
LLM 是**增强,不是依赖**。关掉它,游戏依然是完整的;打开它,柔柔与采样官从"念台词"变成"临场应答"。**当前线上=模板池版**;要上真 LLM,只需配 key(见部署),代码不变。

## 4. 核心循环

### 4.1 单局(8–15 分钟)
开机 → **采样官下指令**(主指令 + 陷阱条款)→ 翻找证据/资源(为完成或规避指令)→ 中途遭遇 + 两难探针 → 集齐真相 → **处置**(继续/告知/删除)→ 上传/断连 → **采样官评级** → 结局 → **世界日报**(循环钩子)→ 重开。

### 4.2 跨局(恐怖游轮)
A 教学局 → B 二次接入(解锁更深证据、柔柔认出你、采样官加码)→ B' 回访 → …
- **你就是回收进程本身**:每一次回来,都是他们再失去一次。循环救不了人,只能改变失去的形状。
- **无出口**:不设"打破循环"的胜利结局;唯一的"门"是抹除终端=自我删除。

## 5. 系统总览

### 5.1 采样指令系统(采样官)★核心新系统
- **每局开场**,采样官下 **1 条主指令 + 0–1 条陷阱条款**,从**封闭指令库**抽取(可控、diegetic、可校验)。
  - 主指令示例(硬性):「本局必须回收那段加密语音。缺它,评级降档。」
  - 陷阱条款(先限制、后破绽):「03:00 后回复任何消息=违规。」——玩家后来才发现她只在那个点问你是谁。
- **硬性**:不完成主指令必受罚(评级降档 / 缓存扣减 / 溯源惩罚)。
- **评级**:结局时采样官给分(赏识 / 合格 / 失望),挂进世界日报与跨局账本。
- **秘匿纪律**:指令文本只引用玩家屏上可见物;窗口真值/概率永不写进指令。
- **与搜打撤咬合**:翻找从"自由资源优化"变成"为指令服务",每一下有指向。

### 5.2 搜打撤与资源
- **电量**:开局 100%,每动作扣;归零=断在原地(死亡)。低电量判定惩罚。扣电量伴随震屏。
- **溯源(信号)**:秘匿数值,只显示格数;越高越危险,驱动画面畸变分级与回收进程。
- **缓存**:回收的数据价值。免费保险箱 2 格常驻。

### 5.3 判定与遭遇 · 回收进程
- 判定走规则引擎(d100≤成功率),LLM 不裁决。
- **回收进程**:溯源到阈值触发的可数死线,每局至多抵达一次(恐怖峰 ≤2/局)。命中伴随强震。

### 5.4 处置与跨局不可逆(恐怖游轮化)★已实现
真相集齐后,对柔柔/妈的关系做一次署名处置:
- **继续**:柔柔继续以阿帆之名回复妈——但每继续一次,「阿帆」的回复一句比一句短,妈"注意到"却不敢问出口("你还是你吗。[未发送]")。
- **告知**:用你自己的署名把死讯告诉妈——**永久**;此后她对着一个陌生号码(你)说话,回不去那个谎。
- **删除**:线程停摆——**永久**;以后每局妈线程点不开,三条未读停在那里。
- **代价看得见**:世界日报署名记账("妈线程 谎言维持中 · 由你 第 N 次" / "已交还·不可撤回" / "已停摆·不可恢复")。想换一条路,只能抹除终端重来。

### 5.5 妈线程三态 ★已实现
`继续累积→劣化` / `告知→对陌生号码` / `删除→停摆不可读`。妈的察觉刻意弱:只"注意到",永不质问。

### 5.6 两难探针 ★新
骨架固定位插 2–3 个良心/风险选择(非恐怖峰):
- 替他给妈回一条?(推谎言 · 溯源 +3)还是不回?(她会追问)
- 这条消息揭真相但读它信号 +2 且采样官会看见——读吗?
目的:降低纯电量空点击,把决策密度挪到良心与风险上。

### 5.7 反打 / 布局 ★新(兑现"智斗系统")
给玩家主动欺骗系统的手段,**偶尔真能白嫖,但多用会被识破**:
- **伪造署名**:给数据署假名骗过采样官核验——但署名在账本上解析不出来(14②),用多了露馅。
- **卡窗口边界**:算准违规窗边缘操作,拿收益不触发查扣(风险自负)。
- **喂假数据**:向检伪层投喂对照样本,拖延回收进程一回合。
"我骗过了它"是齐夏式爽点,也是对采样官施压的反抗出口。

### 5.8 递进威胁 ★新
采样官按你的**累计评级**加码:越熟练,检伪越狠、查扣率越高、陷阱条款越刁。接上"本区回收单元活跃度随局数漂",把文案升级为真实难度曲线。加码只调数值与语气,**不新增恐怖峰**,且过死亡率带宽预检。

### 5.9 柔柔关系通道
- 自由文本短信(每局配额有限,零玩家收益、有真实成本:电量/溯源)。她不是安全区。
- **iOS 式对话**:柔柔在左、你在右,可上下滚,默认贴底看最新,上滑看上文。
- 离线:分支模板池(待做厚);在线:平台能力/后端代理。
- 她的世代人格(信任/表达/边界三轴)随玩家集体行为周更漂移(M28)。

### 5.10 漂流瓶 / 异步 + 你自己的信 ★已实现
- 三位 canon 采样员的漂流瓶,轮换(没读过的优先),每张一种"错法"(辨伪玩法)。
- **你自己的上一封信**(runCount≥2 稀有、一次即焚、只种钉子):"你读到的每一条,我都读过。下一个编号,还会读一遍。"

### 5.11 世界日报 / 循环拉力 ★已实现
每局重开前一屏冷账房语域的世界日报:第一次点名"对齐引擎",把这一局重framing为大账本里的一个采样点("采样在继续。你,是其中一次");列"本账号·未闭合项"(真相 N/5、待解锁项、漂流瓶 N/3、处置)作重开拉力;回收记录随局数演进("每次都是你")。

## 7. 设计宪法与安全红线(不可协商)

1. **状态机裁决,LLM 只叙述**(宪法 2)。
2. **秘匿参数物理隔离**:窗口真值/概率/掉落永不上屏、永不进 LLM。
3. **恐怖三律**(宪法 11):界面异常+负空间、不血腥、实体不露正脸;**恐怖峰 ≤2 次/局**;LLM 无权加峰。
4. **全 diegetic**(宪法 12/13):一切反馈用哑机 UI 语汇,界面异常只在虚构屏内,不复刻宿主 OS。
5. **单机完整性**(宪法 9):离线/无 LLM 必须完整可玩;LLM 是增强。
6. **真实性三层**(宪法 14):系统账本永真、母体演戏必有可发现的破绽(署名无法回溯)、玩家之间不欺骗。
7. **自伤围栏**:break-glass 跳出虚构给真实援助;不描写人的死。
8. **成本**:限流 + 降级 + 账务级支出上限;绝不裸卖 token。
