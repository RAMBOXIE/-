## 0. 全局图景

在线异步多人的"逃离算法世界"长线游戏。玩家是被采样的实例,在数据基础设施世界(四类管辖区)里被母体反复采样、回收;全体玩家共同推进世界阶段 Stage 0→N,终极=全员逃离。
**当前在做的是一个垂直切片**:M2 数字原型——单副本 PvE 教学局「失踪采样体的手机」+ 剧本 B + 异步漂流瓶最小闭环 + 多个 AI 角色最小闭环。

## 1. 角色阵容(本版新增两个 LLM 角色)

- **母体 / 对齐引擎**:更高维采样计划本体,随现实 AI 升级(代际 gen.N),不露正脸。
- **采样官(权威 AI · LLM)**:母体在本终端的发令者与评级者;下采样指令、打分、逐局加码。语气**挑衅激将**。见 §5.1。
- **柔柔(亲密 AI · LLM)**:阿帆的伴侣实例,替他以他之名回复来信 47 天;在观察你。
- **妈(人性标尺 · 分态 LLM)★新**:阿帆的母亲。**欺骗期=脚本**(她信着,察觉刻意弱);**告知后=LLM**(她对着陌生号码你说话,每次不同)。见 §5.6。
- **误触号码的陌生人(每局一个 · LLM)★新**:一个把短信发错到这台机子的号码,可能是真人、也可能是伪装的对照样本。读信免费,行动可能得线索、也可能踩饵。见 §5.11。
- **阿帆**:已故登记用户,只存在于旧消息。
- **采样员(你)**、**异步采样员**(#6404-C 等 + 上一个你)。

> **四个 LLM 声音,四种关系**:采样官(逼你)/ 柔柔(缠你)/ 妈(照见你)/ 陌生人(试探你)。都在一台机子里。

## 2. LLM 如何作用于游戏 ★(本版重写:LLM 原生 + 模板兜底 + 受限裁决)

### 2.1 定位变化
从"离线完整 + LLM 增强"正式转为 **"LLM 原生"**:最佳体验依赖 LLM。但**每个 LLM 面都保留一个够用不塌的模板池底**——在线惊艳,离线平淡但不残(宪法 5 新措辞)。

### 2.2 LLM 碰哪些
| 面 | 角色/用途 | 自由度 | 离线兜底 |
|---|---|---|---|
| 关系通道 | 柔柔应答 | 高(受人格核+lint) | 分支模板池 |
| 发令/评级 | 采样官措辞态度 | 中(指令内容仍状态机) | 挑衅模板措辞 |
| 告知态 | 妈对陌生号码说话 | 中(强安全护栏) | 3–4 条脚本 |
| 误触号码 | 陌生人对话 | 高(canon 权重低) | 分支模板池 |
| **遭遇叙述** | 讲活遭遇 + 在引擎批准分支里挑 + 定强度语气 | **受限裁决** | 脚本分支 |

### 2.3 受限裁决(遭遇)★新
遭遇不再是"引擎裁决 + LLM 只叙述",升级为**受限裁决**:
- **数值永远归引擎**:伤害、掉落、溯源、生死、缓存,状态机说了算。
- **LLM 负责**:把遭遇讲活、**在引擎预先批准的几个分支里挑一个**、定强度与语气。
- 玩家感受到临场感与每次不同;账本仍可信、骗不动;离线退化成脚本分支。
- **红线**:LLM 永不直接决定资源与生死(见宪法 2 新措辞)——那会破坏账本永真且在异步多人里可被越狱刷分污染共享世界。

### 2.4 三级降级链(所有 LLM 面同架构)
① 平台能力(Artifact) → ② 后端代理(Netlify,人格核在服务端 system 参数) → ③ 模板池。

### 2.5 铁的纪律(已实现/门禁守着)
人格核在服务端 / 秘匿参数永不进 prompt / assistant 轮 HMAC 验签 / 输出 lint / 危机 break-glass。

### 2.6 成本与部署(LLM 原生的代价,必须配套)
- 一局要打多次 LLM(采样官下令+评级、柔柔、妈告知态、陌生人、遭遇裁决)。量级远超现在。
- **必须**:每把 key 单开 workspace + **账务级支出上限** + 更狠的限流 + 全部走 501/降级兜底。
- **部署**:公网要**配 key**才是完整体验;不配 key=模板兜底版(能玩、平淡)。

## 3. 核心循环

### 3.1 单局
开机 → **采样官下指令**(主指令+陷阱条款)→ **误触号码进来一条**(线索/饵)→ 翻找(为完成/规避指令)→ 遭遇(受限裁决)+ 两难探针 → 集齐真相 → **处置**(继续/告知/删除)→ 上传/断连 → **采样官评级** → 结局 → 世界日报 → 重开。

### 3.2 跨局(恐怖游轮)
A → B → B' …;你就是回收进程本身,循环救不了人只能改变失去的形状;无出口,唯一的门是抹除终端=自我删除。

## 4. 系统(只列因决定而变/新增的;其余见 v1.1 §5)

### 5.1 采样指令(采样官)= canon M20/M22 下沉到每局
- 每局下 **1 主指令 + 一个问题/陷阱条款**,从封闭指令库抽。
- 三响应(canon):**服从**(达标→配额+掉落 buff,P↑)/ **破局**(伪造/替身骗过检验→全额奖励不付真代价=偶尔白嫖;多用被检伪识破)/ **无视**(个人布控+1,P↓)。
- 拍板:**挑衅激将 · 硬性(不达标必罚)· 破局偶尔白嫖**。
- 递进:采样官按累计评级加码(检伪更狠/查扣更高/条款更刁),只调数值语气,不新增恐怖峰,过死亡率带宽预检。

### 5.3 遭遇 · 受限裁决
见 §2.3。数值归引擎,LLM 讲活+挑分支+定强度;离线脚本分支。

### 5.6 处置 · 妈线程分态 ★改
- **处置三选**(继续/告知/删除)+ 跨局不可逆(告知/删除永久上锁)——已实现,不变。
- **妈线程分态**:
  - `欺骗期(继续累积)` → **脚本劣化**(「阿帆」回复逐句变短;她"注意到"却不敢问,"你还是你吗。[未发送]")。**保持脚本**,因为这条恐怖精度靠手调。
  - `告知后` → **LLM**:她对着陌生号码(你)说话,每次不同。**强安全护栏**:她永不主动提死、不哀求、不自伤;走 break-glass;离线退化为 3–4 条脚本。
  - `删除后` → 停摆屏(不可读)。

### 5.11 误触号码的陌生人(每局一个)★新
- **每局开场附近**,一个陌生号码把短信发错进来。
- **本质二选一**(接辨伪):真人误触(真线索,可能引你走向某处)/ 伪装的对照样本(饵)。真伪 per-run seed。
- **读信永远免费零风险**(读信分离);**按他给的线索行动**才可能得利或踩饵("不慎更受伤")。
- LLM 渲染其应答 + 模板兜底;canon 权重低,LLM 自由度可高。
- 收益上限受控:陌生人给的是"线索/情绪",不直接给资源硬值(资源仍引擎裁决)。

## 6. 设计宪法(本版重写第 2、5 条;其余保持硬)

1. **受限裁决(改自旧"LLM 不裁决")**:数值、生死、掉落、溯源、缓存——**永远由状态机裁决**;LLM 只负责叙述、在**引擎预先批准的分支**里挑选、定强度与语气。**LLM 永不直接决定资源与生死。** 越狱与提示注入挡在"选择被引擎限定"这道墙外。
2. **秘匿参数物理隔离(硬)**:窗口真值/概率/掉落永不上屏、永不进任何 prompt。——松了辨伪与解谜即死,不松。
3. **署名无法回溯(硬)**:母体演戏必有可发现的破绽=署名在账本上解析不出来。——它就是辨伪玩法本身,不松。
4. **系统账本永真(硬)**:仪表/掉落表/预测/日报全有遥测背书,禁编造。——异步多人的信任地基,不松。
5. **LLM 原生 + 模板兜底(改自旧"单机完整性")**:最佳体验依赖 LLM;每个 LLM 面保留够用的模板池,离线平淡但不残。公网完整体验需配 key + 账务级支出上限。
6. **恐怖三律(硬)**:界面异常+负空间、不血腥、实体不露正脸;**恐怖峰 ≤2/局**;LLM 无权加峰。
7. **全 diegetic(硬)**:反馈用哑机 UI 语汇,只在虚构屏内,不复刻宿主 OS。
8. **自伤围栏(硬)**:break-glass 跳出虚构给真实援助;不描写人的死;妈/陌生人/柔柔/采样官全部受此约束。
9. **母本因果不可改写(硬)**:永不出现 Eve 系副本;采样计划之谜受 Bible §13 约束。
