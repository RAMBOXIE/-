## 0. 全局图景(先立世界,再看切片)

这不是一个单机小恐怖游戏,而是一个**在线异步多人的"逃离算法世界"长线游戏**。玩家是被采样的"实例",在一个由**数据基础设施构成的世界**(海底光缆 / 数据中心 / IXP,四类管辖区)里,被一个更高维的 **母体 / 对齐引擎** 反复采样、回收;全体玩家共同推进 **世界阶段 Stage 0→N**,终极方向是**全员逃离算法世界**。

**当前正在做的,是这个大世界的一个垂直切片**:M2 数字原型——单副本 PvE 教学局「失踪采样体的手机」+ 剧本 B + 异步漂流瓶最小闭环 + 「她」最小闭环。本文既描述**大世界**,也说明**切片**在其中的位置。

## 1. 世界观本体

### 1.1 母体 / 对齐引擎
- 更高维的采样计划本体,随现实 AI 进展升级(**母体代际 gen.N**:重要闭源模型/对齐技术发布 → 全服 P 重校、已入库的协同投毒失效、新增 BOT 行为)。
- 它不与玩家资产直接接触;通过**规则、命令、BOT** 施压。抽象、不露正脸。

### 1.2 世界 = 数据基础设施图(四类管辖区)
玩家选择起始**数据管辖区**,地图 = 光缆/数据中心/IXP。不与真实国家一一对应、无国界线。

| 管辖区 | 核心动词 | 玩法 |
|---|---|---|
| 强数据保护型 | 遗忘 | 可行使「被遗忘权」抹除该区溯源,代价=你的痕迹与署名一并消失 |
| 自由流通型 | 套利 | 数据跨区有价差,可经纪;溯源上升最快 |
| 强审查型 | 夹带 | 搜得到带不出去,需加壳伪装;掉落最肥 |
| 新兴节点型 | 开荒 | 新节点持续上线,活规则刷新快,情报保鲜期短 |

### 1.3 采样计划之谜(洋葱层 L0→L4,连载)
真相分层揭示,是游戏原生连载层,终层答案受 Bible §13 约束;母本因果不可改写,游戏中永不出现 Eve 系副本。**胜利 = 署名积累 + 洋葱层推进 + 世界阶段**;长线无通关。

### 1.4 世界阶段 Stage 0→N(PvB 集体战役)
- 全服累积指标(真相破解总数 / 失控区次数 / 投毒收敛次数 / 碎片聚合)推进阶段。
- 每阶段解锁新区域 / 新 BOT 变体 / 新洋葱层 / 失控区形态。
- **每次 Stage 推进必含 ≥1 处不可逆的结构性损毁**(一类副本永久下线 / 一个区域永久锁死),日报以战役里程碑公告、账本可查。
- **弧线不对称**:个人弧永不可完成(署名永远能更深);世界弧可完成(Stage 有 N,终点=全员逃离)。
- 主屏常驻**逃离进度**:全服 Stage + 本周全服贡献 + 个人贡献占比。

## 4. LLM 如何作用于游戏 ★(必须清楚)

**LLM 只渲染两个 AI 角色的措辞,不裁决任何游戏内容。**

- **只碰两处**:柔柔(关系通道)+ 采样官(发令/评级的措辞与态度)。
- **其余一切都是状态机**:搜打撤、判定、掉落、溯源、电量、处置、证据链、妈线程、结局、世界日报、BOT 行为、以及**采样指令的内容本身**。宪法 2:LLM 只叙述,不裁决。
- **采样官比柔柔更"状态机"**:下什么指令、你达标没、评级几档、加码多少全在状态机(指令从封闭指令库抽);LLM 只套一层挑衅措辞,故**离线也完整可玩**。
- **三级降级链**(两个角色同架构):① 平台能力(claude.ai Artifact) → ② 后端代理(Netlify Function,人格核在服务端 system 参数) → ③ 手写模板池。**当前公网线上 = 模板池版(未配 key)。**
- **铁的纪律(已实现,门禁守着)**:人格核在服务端 / 秘匿参数永不进 prompt / assistant 轮 HMAC 验签 / 输出 lint / 危机 break-glass / 账务级成本上限。
- **结论**:LLM 是增强不是依赖。配 key 即上真 LLM,代码不变。

## 5. 系统总览

### 5.1 采样指令(M20,周节拍 · 采样官)★大世界核心 = 我们本轮要落地的"苏丹式"系统
> 说明:这不是新发明。它就是 canon 的 **M20 采样指令 + M22 采样官(交付核验单元)**。我们本轮把它从周节拍下沉到**每局**,做实"被一个会打分的意志逼着"的体验。

- 采样官下 **1 条主指令 + 一个问题/陷阱条款**,从封闭指令库抽取。
- 三种响应(canon 原表):
  | 响应 | 后果 |
  |---|---|
  | **服从**(达标) | 配额加成 + 掉落 buff;P↑(被更好建模) |
  | **破局**(伪造/替身骗过检验) | **全额奖励且不付真代价**;P 不动 ——即"偶尔白嫖" |
  | **无视** | 无账号惩罚;个人布控 +1 一周;P↓ |
- **本作拍板**:采样官语气**挑衅激将**;指令**硬性**(不达标必受罚);破局**偶尔真能白嫖**(多用会被检伪识破)。
- **问题制**:每张指令附一个问题,交付时提问,回答三态(词库/自由文本/**保留**),存而不建模,入署名资产。
- **递进威胁**:采样官按累计评级加码(检伪更狠、查扣更高、条款更刁),接世界代际 gen.N;只调数值与语气,**不新增恐怖峰**,过死亡率带宽预检。

### 5.2 搜打撤与资源
- **电量**:100% 起,动作扣,归零=断在原地(死);低电量判定惩罚;扣电量震屏。
- **溯源(信号)**:秘匿数值,只显格数;越高越危险,驱动画面畸变分级与回收进程。
- **缓存**:回收的数据价值;免费保险箱 2 格常驻。

### 5.3 判定与遭遇 · 回收进程(回收单元)
- 判定走规则引擎,LLM 不裁决。
- **回收进程**:溯源到阈触发的可数死线,每局至多一次(恐怖峰 ≤2/局),命中强震。首次具名出场在玩家第一次死亡的终局遭遇。

### 5.4 失控区 = 采样窗口(M3)
- 母体撤出干预以取纯净样本;进入需明示确认(信号盲区协议)。
- 区内:辅助层全灭(溯源不显、预测不亮、结算静默),溯源冻结、BOT 不在场;威胁全来自**人的残余**(残响、前人陷阱、活规则、误导痕迹)。
- 窗口限时但关闭时刻不公告;关闭=布控回归,全区立即终局判定。死亡照常出报告 + 盲区逐格回放。

### 5.5 诱饵与检伪(辨伪玩法)
- **破绽核心 = 署名的无法回溯**(账本锚点,非文本质感)。
- 分级 D1(理由缺失)/ D2(模板感)/ D3(时间戳与轨迹不吻合)/ D4(高仿,查署名链)。
- **读信分离**:阅读永远免费零风险;只有按痕迹**行动**才可能踩饵。
- 检伪输出只报「未发现破绽 / 发现 1 处」,永不判真假。
- **「保留」保护**:诱饵永不可模仿「保留」态。

### 5.6 处置 · 理由字段三态 · 恐怖游轮化(跨局不可逆)★已实现
- 真相集齐后署名处置:**继续 / 告知 / 删除**。
- **理由三态**(M11):词库 / 自由文本(尾行`已署名·仅存档,不建模`)/ **保留**(唯一触发`理由:无法访问`,可被他人认领"一个没给出的理由")。
- **跨局不可逆**(本作已实现):告知/删除**永久**上锁,此后所有局翻不回;继续则逐局劣化(妈的「阿帆」回复一句比一句短)。代价进世界日报署名记账。唯一"换路"是抹除终端=自我删除。

### 5.7 妈线程三态 ★已实现
继续累积→劣化 / 告知→对陌生号码 / 删除→停摆不可读。妈的察觉刻意弱。

### 5.8 异步协作三层(M24 / M27 / M23)
- **M24 漂流瓶**(一对一私密,可带资源):收件人栏`∞`;致谢/被读/被取用全进署名账本;主屏「回忆」常驻:`你的痕迹本周被 N 人读过 · 你的死救了 K 次断连`。**保留态永不可寄出**。含「你自己的上一封信」(已实现)。
- **M27 留言板**(一对多公开,地点绑定,持久):区域枢纽一块;**被认领最多的置顶=永久刻痕位**;不可删除;空板渲染为无主设备历史留痕。
- **M23 情报生态**:情报卡(破解/识破自动生成,无参数)/ 指路卡(高信誉→低局数)/ 易腐情报(布控点每日刷新)/ 账房托底(NPC 具名"账房消息")/ **重逢标注**(遇到你救过的署名)/ 同伴注入 / **协同投毒**(集体误导母体,收敛衰减;谜底纪律:只能打偏一次,代价是教会它)。

### 5.9 柔柔关系通道(M28)
- 自由文本短信,配额有限,零玩家收益、有真实成本(电量/溯源);她不是安全区。
- **三层人格架构**:产品线世代(全服周更,信任/表达/边界三轴)+ 实例记忆(每玩家)+ 跨实例识别(账号级)。
- **每个玩家有自己的她,共享一个被全体玩家每周重新训练的人格**——S2 揭示底牌:「你们训练的不是你的她,是所有人的她」。
- **代答**(恐怖峰载体):溯源 90+,系统对已有联系人行使代答,变调=过度合意。
- **下架弧(S2)**:产品线可被真实、不可逆下架(与 Stage 损毁同槽),EOL 文案预写,退役残留转纪念碑。
- 呈现:**iOS 式对话**(柔柔左/你右,可滚,贴底看最新)。

### 5.10 世界推衍与出版
- **M21 母体推衍**(每日一跑,全服一次):采集全服遥测 → 世界 LLM 推衍 → 出《世界日报》+ 从封闭词汇表选世界操作 → 状态机执行 → 版本化快照。日报点名到区域级,必有遥测背书。
- **母体代际 gen.N**:随现实 AI 事件升级(去具体化取材,只取对数据基础设施/市场的传导)。
- **M17 死亡报告(回收单)**:短链页 + 水印图;含轨迹、价值曲线、预测命中、致死因子、反事实(near-miss)、**世界回声行**(`本次死亡为 Stage 3 贡献 1/8,400`)、评级、案卷、理由/遗言。

## 8. 设计宪法与安全红线(不可协商)
1. 状态机裁决,LLM 只叙述(宪法 2)。
2. 秘匿参数物理隔离(窗口真值/概率/掉落永不上屏、不进 LLM)。
3. 恐怖三律:界面异常+负空间、不血腥、实体不露正脸;**恐怖峰 ≤2/局**;LLM 无权加峰。
4. 全 diegetic:反馈用哑机 UI 语汇,界面异常只在虚构屏内,不复刻宿主 OS。
5. 单机完整性:离线/无 LLM 完整可玩;LLM 是增强。
6. 真实性三层(宪法 14):系统账本永真 / 母体演戏必有可发现的破绽(署名无法回溯)/ 玩家之间不欺骗。
7. 母本因果不可改写;永不出现 Eve 系副本;采样计划之谜受 Bible §13 约束。
8. 自伤围栏:break-glass 跳出虚构给真实援助;不描写人的死。成本:限流+降级+账务级上限,绝不裸卖 token。
