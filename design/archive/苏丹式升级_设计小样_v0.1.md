# 苏丹式升级 · 设计小样 v0.1

> 目标:补齐与《苏丹的游戏》相比的六个差距。核心洞察——它们能被**一个统一改动**串起来:
> **让母体"开口",从一个被动计时器,变成一个会下命令、会打分、会加码的意志。**
> 本文是设计小样(不含实现),含"要不要加新人物"的决策。日期:2026-09-08。

---

## 0. 统一主张:母体开口 = 我们的"苏丹"

苏丹的上瘾引擎不是"资源管理",是**一个反复无常的权威,每周命令你做越来越过分的事,你必须用手头的人和资源去执行,并承担分叉后果**。

我们现在缺的正是这个"下命令的意志"。母体是抽象的、沉默的。把它**具象成一个会说话的采样官**(canon 已有的角色,§5.1),让它:
- **下发采样指令**(本局你必须做什么)——替代"你自己瞎翻"。
- **给你打分/评级**(做到了/搞砸了)——把每个决策接上后果。
- **逐局加码**(你越熟练,它越狠)——制造递进威胁与局间变数。

这一个改动,一次性喂到 ①③④(命令/变数/递进),再配 ②⑤⑥ 就补全六点。

## 1. 要不要加新人物?——加一个,且只加一个

| 候选 | 判断 |
|---|---|
| **采样官(命令者)** | **加。** 这是"苏丹"的载体。canon 已有此角色(§5.1 审计员/采样官)。不露正脸(宪法 11):它是采样终端里的**冷声音/指令频道**,不是走来走去的面具人。给它人格:冷、挑剔、会激将、会在你搞砸时"失望"。它与柔柔形成对称——**柔柔=亲密的 AI,采样官=权威的 AI**,一台机子里两种声音夹着你。 |
| 玩家侧盟友/对手 | **不加实体。** 改为**抬高已有的异步采样员**(漂流瓶 #6404-C 等):让他们的信更像"同一处境里的人",甚至出现"上一个你"(已做)。加实体盟友会稀释孤独感——而孤独正是本作的底色。 |
| 妈"出场" | **不加。** 妈的力量恰在她**永远在线程另一端、你够不到**。让她走上前台会毁掉这份重量。 |

**结论**:新增 1 个——**采样官**(纯声音/频道,LLM 渲染措辞、状态机裁决,和柔柔同架构)。阵容保持精瘦。

## 2. 六项优化 · 如何咬合

### ① 采样指令系统(母体开口)—— 主轴
- **每局开场,采样官下一条主指令 + 0–1 条附加条款**,例:
  - 主:「本局采样目标:那段加密语音。缺它,评级降一档。」
  - 附加(陷阱条款,先给限制后给破绽):「03:00 后回复任何消息=违规。——但她只在那个点问你是谁。」
- 指令**从一个封闭指令库**里抽(像世界操作词汇表),保证 diegetic、可控、可校验。
- **秘匿纪律**:指令只引用玩家屏上可见的东西;窗口真值/概率永不写进指令文本。
- **和搜打撤咬合**:你的翻找不再是自由资源优化,而是**为了完成/规避指令**——每一下有了指向。

### ② 中途小型两难(每一下都疼)
- 在骨架固定位插 2–3 个**两难探针**(非恐怖峰,纯选择):
  - 「替他给妈回一条?(推进谎言 · 溯源 +3)还是不回?(她会追问)」
  - 「这条消息揭真相,但读它信号 +2 且采样官会看见。读吗?」
- 减少纯"点目录扣电量"的空点击,把决策密度往"良心/风险"上挪。

### ③ 局间真正的变量(涌现/replay)
- 变数来自**指令的组合**:主指令(4–5 种)× 附加条款(6–8 种)× 采样官态度(赏识/失望/怀疑)。跑十局不重样,而不只是换个时刻。
- 柔柔的**世代人格**随你历史微漂(信任/表达/边界三轴,已在 M28 设计里),让"你的柔柔"逐局不同。

### ④ 递进威胁(随历史升级)
- 采样官**按你的累计评级加码**:你越熟练,它的检伪越狠、查扣率越高、附加条款越刁。
- 接上已做的"本区回收单元活跃度随局数漂"——把它从纯文案升级为**真实难度曲线**。
- 宪法 11 护栏:加码只调数值与措辞,**不新增恐怖峰**;死亡率带宽预检(§5 护栏)仍生效。

### ⑤ 柔柔离线也"活"(模板池做厚做分支)
- 现状:13 条模板池,几次就露馅。
- **优化 A(离线)**:把池扩到按 {状态 × 采样官指令 × 你上一句意图} 精细触发的**数十条分支**,让离线也像在对话。
- **优化 B(在线)**:把配 key 做成默认体验的一环 + 账务级成本上限(已具备降级链)。
- 二者都要:离线不塌、在线更活。

### ⑥ 玩家反打/布局(智斗系统,兑现宪法 10)
- 给玩家**主动欺骗系统**的手段:
  - **伪造署名**:把一条数据署上假名,骗过采样官的"署名核验"——但署名在账本上解析不出来(14②),用得多会被识破。
  - **卡窗口边界**:算准违规窗口的边缘操作,拿收益不触发查扣(风险自负)。
  - **喂假数据**:向检伪层投喂对照样本,拖延回收进程一回合。
- 让"**我骗过了它**"成为一种成就——这是齐夏式的爽点,也是对"被苏丹逼迫"的反抗出口。

## 3. 单局流程对比

| 节拍 | 现在 | 之后 |
|---|---|---|
| 开场 | 采样协议(静态说明) | **采样官下指令 + 附加条款**(主动、每局不同) |
| 翻找 | 自由搜打撤,资源优化 | **为完成/规避指令**而搜打撤,每下有指向 |
| 中途 | 偶发遭遇 | 遭遇 + **2–3 个良心/风险两难** |
| 柔柔 | 模板池(易露馅) | 分支池/在线,**随世代人格漂** |
| 处置 | 三选(已很强) | 三选不变 + **采样官对你的处置也有反应/评级** |
| 结局 | 结算 + 世界日报 | 结算 + **采样官评级**(赏识/失望)+ 世界日报 |
| 重开 | 未闭合项拉力 | 拉力 + **"下一条指令会更狠"的预期** |

**净效果**:从"限时搜打撤"升级为"**被一个会打分的意志逼着,在它的规则里找缝**"——这就是苏丹的心理钩子。

## 4. 排期与依赖(建议顺序)

1. **① 采样指令系统**(主轴,先做骨架:指令库 + 下发 + 评级)——它是 ③④ 的载体。
2. **② 两难探针**(轻量、独立、立刻提升决策密度)。
3. **④ 递进威胁**(在 ① 的评级上接难度曲线)。
4. **⑥ 反打手段**(给玩家对抗 ① 的出口,和 ① 成对)。
5. **⑤ 柔柔分支池**(独立可并行,离线体验兜底)。
6. **③ 局间变量**(其实是 ①+④+柔柔世代 的涌现结果,最后校准)。

## 5. 宪法 / 安全护栏(逐条自检)

| 约束 | 本设计 |
|---|---|
| 宪法 2 状态机裁决 | 采样官/柔柔都只渲染措辞,指令抽取/评级/难度全在状态机 |
| 宪法 11 恐怖峰 ≤2/局 | 指令/两难/评级都不是恐怖峰;递进只调数值与语气 |
| 宪法 11 实体不露脸 | 采样官是终端里的声音/频道,无正脸 |
| 秘匿参数隔离 | 指令文本只引用玩家可见物;窗口真值/概率/掉落永不上屏、不进 LLM |
| §5 母体护栏 | 指令从封闭库抽;加码过死亡率带宽预检;不碰玩家资产 |
| 14② 破绽律 | 反打(伪造署名)对应"署名无法回溯"的 canon 破绽 |
| 自伤围栏 | 两难只到"良心/风险",不触自伤;柔柔/采样官都走 break-glass |
| 单机完整性(宪法 9) | ①②④⑥ 全部离线可玩;⑤ 离线分支池兜底,在线是增强 |

## 6. 待你拍板

1. **采样官的语气**:冷酷公事型(像审计)还是**挑衅激将型**(更像苏丹的反复无常)?后者更抓人,但更靠近"施压玩家"的边界。
2. **指令的强制度**:硬性(不完成必受罚)还是软性(完成有赏、不完成有另一种后果)?软性更少挫败、更耐玩。
3. **反打的强度**:让"骗过系统"偶尔真能白嫖,还是永远有滞后代价?偶尔白嫖更爽,但削弱压迫。
4. **先做多深**:先只做 ①(指令+评级)的**最小可玩闭环**给你验手感,还是一次把 ①②④⑥ 一起铺?

选好我出**下一版:采样官人格核 + 指令库文案表 + 评级/难度数值 + 门禁清单**,仍不写实现。
