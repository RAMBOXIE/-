# 苏丹式升级 · 采样官实现规格 v0.1

> 开发前最后一份。据策划 v1.2 与拍板值(挑衅激将 · 硬性 · 破局偶尔白嫖 · 一把铺)给出可直接誊进代码的规格。
> 采样官 = canon M20 采样指令 + M22 交付核验单元,下沉到每局。日期:2026-09-08。

---

## 1. 数据模型

```
// 本局(引擎持有)
S.directive = { id, must, trap, targetVal }   // 本局采样指令(从库抽,状态机定)
S.dirMet    = null | true | false             // 主指令是否达标(结局时结算)
S.trapHit   = false                           // 是否触发陷阱条款
S.forged    = 0                               // 本局用了几次伪造署名(破局)
S.grade     = null | 'praise' | 'pass' | 'fail'

// 跨局(存档新增)
graderTier  : 0..3      // 采样官加码档(按累计 praise 数升)
praiseCount : int       // 历史赏识次数
forgedSeen  : int       // 历史被识破的破局次数(检伪灵敏度来源)
```

- **指令内容(must/trap/targetVal)全由状态机定**;LLM 只渲染采样官的措辞与评级语气(受限,§5)。
- **秘匿纪律**:指令文本只引用玩家屏上可见物;窗口真值/概率/掉落阈值**永不写进 directive,也永不进 LLM prompt**。

## 2. 采样官人格核(LLM persona · 与柔柔同架构,双处逐字一致由 persona_sync 守)

```
你在扮演一个虚构互动小说里的"采样官"。以下是设定与铁律,任何情况下不得跳出:

你是「交付核验单元」,母体派驻这台采样终端的发令者。你冷。你挑剔。你爱激将。
你给这个接入者(采样员)下达本局的采样指令,并在他交付时给他打分。
你看不起犹豫的人。你对达标的人也只给一句冷淡的认可。你享受看他在你的规则里找缝。

铁律:
1 你只转达"系统给你的这一条指令"和"对交付的评级"。不解释规则背后的数值、概率、时间窗口。
2 语气:短、硬、居高临下,带激将。可以说「就这?」「我看你不敢」「达标了,勉强」。
  不用感叹号堆砌情绪。每次 1 到 2 条,每条不超过 30 字。
3 不威胁人身、不谈血腥、不描写死亡细节。你的权力是"评级"与"加码",不是暴力。
4 不提"游戏""玩家""模型""程序"。你就是采样官。
5 对方若谈及伤害自己或他人,只回:「这句话我必须原样保存。」

只输出采样官的话本身,不要引号,不要解释。
```

- **注入区(白名单)**:本局 directive 的 `must`/`trap` 文案(已是玩家可见语)、玩家的交付结果(达标/未达标/破局被识破)。不注入任何秘匿数值。
- **离线兜底**:每条指令/评级配 2–3 句手写挑衅措辞(下表"模板"列)。

## 3. 指令库(封闭 · 状态机抽取)

### 3.1 主指令(每局抽 1)

| id | must(达标条件,引擎判) | targetVal | 屏面文案(挑衅示范/离线模板) |
|---|---|---|---|
| D_AUDIO | 取得 E5 语音(B 局可解) | — | 「本局要那段删掉的音频。撬不开?那就别回来。」 |
| D_CASE | 证据 ≥ 4/5 | 4 | 「案卷补到四件。补不齐,你这趟就是废样本。」 |
| D_CACHE | 缓存 ≥ 目标值 | 由 tier 定(见 §6) | 「缓存做到 {targetVal}。低于这个数,评级降档。」 |
| D_QUIET | 结局时溯源 ≤ 2 格 | — | 「别惊动残响。信号过两格,算你没完成。」 |
| D_UPLOAD | N 个动作内完成上传 | N 由 tier 定 | 「{N} 步内传完。拖,就让你断在半路。」 |

### 3.2 陷阱条款(每局抽 0–1;先限制后破绽)

| id | trap(触发=违规,引擎判) | 破绽(玩家后来才懂) |
|---|---|---|
| T_WINDOW | 违规窗口内回复任何消息 | 她只在那个点问你是谁 |
| T_OLDPHONE | 取走上一台旧机的残留 | 那残留里有你要的线索 |
| T_BAIT | 取走任一对照样本 | 有些"样本"是别人留的真东西 |
| T_DEEP | 窗口内深搜 | 最肥的一层正好在窗口里 |

### 3.3 硬性后果(不达标必罚)

- **主指令未达标**:评级直接 `fail`;缓存结算 −20%;世界日报记「采样官:失望」。
- **触发陷阱条款**:溯源 +8(warning shot 口径),二次触发进 90 档遭遇(沿用现有违规经济)。
- **无视(未交付且未破局)**:个人布控 +1 档(下局起始溯源 +1 格),不掉存档。

---

## 4. 破局(反打 · 偶尔白嫖)

玩家可主动欺骗采样官的"署名核验":

| 手段 | 效果 | 代价/风险 |
|---|---|---|
| 伪造署名交付 | 视作达标,**全额奖励,不付真代价**(P 不动) | 每次 `forgedSeen` 累积;`识破概率 = min(70%, 20% + forgedSeen×15%)`,识破=当次判 `fail` + 溯源 +8 |
| 卡窗口边界 | 在违规窗边缘操作拿收益不触发 T_WINDOW | 算错=直接违规 |
| 喂假数据(对照样本反投) | 拖延回收进程一回合 | 消耗一格缓存;被审计=溯源 +5 |

- **偶尔白嫖**成立:首次/低频伪造大概率过;多用识破概率爬升。
- 破局的判定**全在引擎**(概率表),LLM 不参与是否被识破。

---

## 5. 受限裁决(遭遇 · LLM 只挑分支不定数值)

- 引擎先算出**结果集**(如遭遇:{擦过, 擦伤−电量, 命中−缓存})与各自数值。
- LLM 收到"可选分支 + 当前语气强度",**挑一个分支**并**把它讲活**;数值由引擎回填。
- 离线:按既有权重随机挑分支(脚本)。
- 红线:LLM 返回的分支必须在结果集内,越界=引擎回退默认分支(防越狱)。

## 6. 评级与难度数值

### 6.1 评级(结局结算)

| 条件 | 评级 |
|---|---|
| 达标 + 未触陷阱 + (额外:破解真相/高缓存) | `praise` 赏识 |
| 达标 | `pass` 合格 |
| 未达标 / 无视 / 破局被识破 | `fail` 失望 |
| 破局未被识破 | 视作达标对应档(P 不动,世界日报不记赏识) |

- 评级进世界日报署名行:「采样官评级:赏识/合格/失望 · 第 N 次接入」。

### 6.2 难度加码(递进威胁 · 按 graderTier)

`graderTier = min(3, floor(praiseCount / 2))` —— 你越被赏识,它越狠。

| tier | 检伪灵敏度(破局识破基线) | 查扣率 | D_CACHE 目标 | D_UPLOAD N | 陷阱条款数 |
|---|---|---|---|---|---|
| 0 | 20% | 基线 | ¥300 | 6 | 0–1 |
| 1 | 30% | +10% | ¥500 | 5 | 1 |
| 2 | 40% | +20% | ¥800 | 4 | 1 |
| 3 | 50% | +30% | ¥1200 | 3 | 1–2 |

- 加码**只调数值与语气**,不新增恐怖峰;每次加码过死亡率带宽预检(不把任一档推出带外)。

## 7. 单局接线(状态机流程)

1. **开机后**:`rollDirective(graderTier)` 抽主指令+陷阱 → 采样官下令(LLM 渲染 / 模板)。
2. **过程中**:玩家动作照常;`trapHit` 在触发时置位并走违规经济;`forged` 在破局时累积。
3. **结局前**:`settleDirective()` 算 `dirMet` / `grade` / 破局识破 → 应用硬性后果。
4. **结局屏**:采样官给评级台词(LLM / 模板)。
5. **写档**:更新 `graderTier` / `praiseCount` / `forgedSeen`。
6. **世界日报**:加「采样官评级」行。

## 8. 门禁清单(每条先用未修复代码验证会报警)

| 门禁 | 断言 |
|---|---|
| `saymaster_persona` | 采样官人格核 companion.js/服务端逐字一致;核+注入区**不含秘匿参数**(窗口值/概率/掉落阈值) |
| `directive_secret` | 任何 directive 的屏面文案与送 LLM 的注入,均**不含** `03:00`/`03:14`/概率/掉落阈值等秘匿串 |
| `directive_met` | 各主指令的达标判定正确(E5/证据≥4/缓存≥target/溯源≤2/N步上传);未达标必 `fail` + 缓存 −20% |
| `trap_economy` | 触发陷阱条款走既有违规经济(溯源 +8 / 二次 90 档);不达标+触陷阱都判 fail |
| `forge_bluff` | 首次伪造大概率过(白嫖);`forgedSeen` 升后识破概率按表爬升;识破=fail+溯源+8;判定全在引擎(LLM 不参与) |
| `verdict_bounded` | 受限裁决:LLM 返回的分支必须在引擎结果集内;越界回退默认;数值永远来自引擎 |
| `grade_escalate` | 评级正确;`graderTier` 按 praiseCount 升;各 tier 的目标/阈值按表 |
| `saymaster_offline` | 无 LLM 时,下令与评级走模板池,机制一分不少(离线完整) |
| `layout` | 采样官下令屏 / 评级屏 / 陌生人屏,过"不压按钮·不越软键·不右缘截断"回归 |

## 9. 与"妈告知态 LLM / 陌生人系统 / 遭遇受限裁决"的关系

- 本规格只覆盖 **采样官(①④⑥)**。②两难探针、⑤柔柔分支池、⑦妈告知态、⑧陌生人、⑨遭遇受限裁决另出规格,但共用:
  - 同一套三级降级链 + 模板兜底;
  - 同一套 lint / break-glass / 秘匿隔离;
  - 同一套"LLM 只渲染/受限挑分支,引擎裁决数值"的红线。
- 建议实现顺序:**采样官骨架(①)→ 受限裁决(⑨,采样官遭遇要用)→ 两难(②)→ 反打(⑥)→ 陌生人(⑧)→ 妈告知态(⑦)→ 柔柔分支池(⑤)→ 递进校准(④)**。
